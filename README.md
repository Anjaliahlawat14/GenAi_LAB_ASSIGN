# Generative AI Lab Experiments

## 📌 Overview

This repository contains a comprehensive set of **Generative AI and Machine Learning experiments** implemented using Python. All experiments are compiled into a single Jupyter Notebook for simplicity and ease of execution.

The notebook demonstrates fundamental as well as advanced concepts including probability distributions, neural networks, GANs, VAEs, and autoregressive models.

---

## 📂 File Structure

* `Generative_AI_Experiments.ipynb` → Contains all experiments from Experiment 1 to Experiment 10

---

## 🧪 Experiments Included

### 🔹 Experiment 1

Generate random samples from probability distributions (Normal, Uniform) and visualize them.

### 🔹 Experiment 2

Implement **Maximum Likelihood Estimation (MLE)** to estimate parameters of a distribution.

### 🔹 Experiment 3

Train a **Neural Network** on benchmark datasets (MNIST/CIFAR-10) using backpropagation.

### 🔹 Experiment 4

Train a **Generative Adversarial Network (GAN)** and analyze generator & discriminator losses.

### 🔹 Experiment 5

Implement a **Flow-Based Generative Model**.

### 🔹 Experiment 6

Implement evaluation metrics using appropriate libraries.

### 🔹 Experiment 7

Evaluate trained model performance using metrics such as accuracy and loss.

### 🔹 Experiment 8

Build **Variational Autoencoder (VAE)** with encoder-decoder architecture.

### 🔹 Experiment 9

Implement **Autoregressive Models** like PixelCNN or PixelRNN.

### 🔹 Experiment 10

Analyze GAN loss functions such as adversarial loss and feature matching loss.
